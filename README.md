# 云阙 YUNQUE

星球与星球之间的滑翔探险：夜的云海上漂着小小的星球，每颗住着一个小世界——灯星、树星、泉星。你从系泊的天舟跃下，乘三角翼在星球之间旅行。（小王子式意象，居民与故事全部原创）

参考方向：莫比斯式云上巨构（实时渲染判例：Sable）。

完成定义（2026-09-06 转向后更新）：能从天舟起飞、滑翔穿云、降落在 ≥3 颗小星球上绕行走一圈并再启程的可玩原型。
停手信号：星球机制可玩后，先与 Jada 确认星球主题清单再做居民与故事内容；不加战斗。
